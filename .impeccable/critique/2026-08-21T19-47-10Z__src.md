## Priority Issues

**[P0] Mobile inbox does not exist**
- Why: Sidebar hidden below `sm`; `/chat` empty state tells you to use the sidebar; new chat lives in that hidden chrome.
- Fix: Conversation list as the small-screen `/chat` index; thread as a second screen; new chat/group in reach.
- Suggested command: `/impeccable adapt`

**[P1] Icon-only 32px sidebar actions**
- Why: New group / new chat / logout are hover-title only; Jordan never finds create; tap targets fail Casey/Sam.
- Fix: Icon+label (or a labeled menu); 44px targets; confirm sign out.
- Suggested command: `/impeccable onboard` (discoverability) / `/impeccable harden` (logout confirm)

**[P1] Group settings is a high-stakes dump**
- Why: Rename, add, promote, remove, leave on one sheet; no confirm; Promote `title` exposes API paths.
- Fix: Confirm leave/remove; hide promote; focus trap; strip API strings.
- Suggested command: `/impeccable distill` then `/impeccable harden`

**[P2] Login fights first-run and geography**
- Why: “Welcome back to the line” vs auto-register; +880 never explained on the landing.
- Fix: First-run headline; human copy for the locked code — or a real country control.
- Suggested command: `/impeccable clarify`

**[P2] Landing sells the write-up; demo sells nothing**
- Why: JWT / GET /auth/me / Socket.io / ids; demo is empty small-talk with “4 members” and two speakers.
- Fix: Human capabilities (unread, reconnect, manage group). Demo a story that needs indigo (unread or group sender).
- Suggested command: `/impeccable clarify` (copy) / `/impeccable delight` (demo)
